## this is a prototype of a 2.9" reflective TFT as optional replacement for the ePaper display

- higher refresh rate
- no ghosting
- higher resolution

- requires:
  - 2.9 inch TFT full-reflective display, driven by ST7305, 2.8V, low power consumption, 24-pin SPI interface
    - https://de.aliexpress.com/item/1005011857123496.html
  - 24Pin FPC connector: FH34SRJ-24S-0.5SH
    - https://de.aliexpress.com/item/1005012997611730.html
  - 0804 caps in 2.2uF and 100nF
