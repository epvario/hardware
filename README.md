## EPVario Hardware ( work-in-progress )

This Repository holds PCB Design files, orderable production files, Case files and information around anything Hardware related.


### Case:
The CAD Design for Case, Backplates and Buttons etc. is available for free on Onshape.com
https://cad.onshape.com/documents/7c7b5a47965e5aa4a5c3c6fc/w/4d91674f4ec0d4e9e5bb48e4/e/9528d9da3515a60f70c45c22

Feel free to create a copy and modify based on your needs

### Mainboard:
The repository contains files of the 4-Layer PCB and the components, compatible to order at JLCPCB for example (a batch of 10 or more)
